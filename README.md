# 📻 ПРОЕКТ «КОНТУР» // ГорСветТехКонтроль

> **Интерактивный веб-триллер в жанре аналогового хоррора и мистического расследования.**  
> Сайт маскируется под закрытый диспетчерский узел неназванного северного города.

---

## ⚡ Быстрый старт (Локальный запуск)

### Требования к окружению
- **Node.js**: `v18.0.0` или новее (рекомендуется `v20+` / `v22`)
- **npm**: `v9.0.0+` (или `pnpm` / `yarn` / `bun`)
- **Браузер**: Chrome 90+, Firefox 90+, Safari 15+, Edge 90+ (требуется поддержка **Web Audio API**).

### 1. Клонирование и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ> kontur
cd kontur
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере: **`http://localhost:5173`**

### 3. Проверка типов и сборка для продакшна
```bash
# Проверка типов TypeScript без сборки
npm run typecheck

# Полная оптимизированная сборка (dist/)
npm run build

# Предпросмотр собранного продакшн-билда
npm run preview
```

## 🕹️ Игровой процесс и механика расследования

Игрок — случайный человек, перехвативший незашифрованную диспетчерскую сессию «ГорСветТехКонтроля». Городская организация официально чинит коммуникации, а неофициально — изолирует пространственно-акустические аномалии.

### Архитектура расследования:
1. **Центральный Хаб (Схема города)**: Интерактивная карта с 4 мигающими точками тревоги и **Терминалом Допуска** `[ __ ] - [ __ ] - [ __ ] - [ __ ]`.
2. **Карта 1: «Объект РЛС-4»** (код: `19`):
   - Клаустрофобия и техно-хоррор.
   - Изучение видеокамеры шлюза В-2, поиск меловой надписи на стене (`714`), разоблачение мертвого техника Соколова в базе данных, экстренная заморозка шлюза за 40 секунд.
3. **Карта 2: «4-й этаж»** (код: `98`):
   - Социальная паранойя и эффект зловещей долины.
   - Изучение чужого смартфона: чат «ЖК Лесной», шепот в голосовом сообщении из ванной, поиск темной квартиры на ночном фото фасада (`38`), вход в щиток ТСЖ (`8804` / `38`) и выжигание реле.
4. **Карта 3: «Маршрут №0»** (код: `04`):
   - Гонка со временем и цифровой сталкер.
   - Погоня с ботом `[ID: ЧИСТИЛЬЩИК]`, стирающим папки архива 1998 года. Радиосканер на частоте `104.2 FM`, запись черного ящика вагона №314, консольный перехват аварийным кодом `3140`.
5. **Карта 4: «Квартира 44а»** (код: `44`):
   - Бюрократический оккультизм.
   - Пульт главного инженера: доклад слесаря о голосах за стеной, акт БТИ с бесконечной площадью, телефонный звонок сущности-имитатора, разоблачение лжи по Уставу и наложение статуса «КАРАНТИН БЕЗ СРОКА ДАВНОСТИ».
6. **Секретный финал**:
   - Ввод ключа `19 - 98 - 04 - 44` в Терминал Допуска.
   - Гаснет янтарная подсветка, включается трансформаторный гул, открывается личное дело оператора с **реальными метаданными устройства игрока** (время, таймзона, экран) и пульсирующей 5-й точкой: «ДАТЧИК ПРИСУТСТВИЯ: 2 ЧЕЛОВЕКА».

## 🛠️ Архитектура и стек технологий

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Фреймворк** | React 19 + TypeScript | Компонентная реактивная модель, типизированные сущности. |
| **Сборщик** | Vite 6 | Мгновенный HMR при разработке, Rollup-оптимизированный бандл. |
| **Звуковой движок** | Web Audio API (`SoundEngine`) | Процедурный синтез индустриальных звуков (гул трансформатора, треск счетчика, рация, зуммер, шаги, удары). Без тяжелых MP3/WAV файлов! |
| **Шейдеры и атмосфера** | Pure CSS (CRT + Scanlines + Vignette + Glitch) | Реалистичные артефакты старого монитора дежурного узла, отключаемые по кнопке в шапке. |
| **Иконки** | Lucide React | Легковесные векторные пиктограммы приборной панели. |
| **Хранилище прогресса** | `localStorage` | Автоматическое сохранение разблокированных фрагментов шифра между перезагрузками страницы. |

## 🚀 Инструкции по деплою (Production)

### 1. Деплой на Vercel (Рекомендуется)
Проект настроен для моментального развертывания на Vercel:
```bash
# Установка Vercel CLI (если не установлен)
npm i -g vercel

# Развертывание
vercel
```
Настройки проекта:
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

### 2. Docker / Nginx
```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
