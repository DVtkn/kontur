## 1. Концепция и Сюжет

Интерфейс закрытого диспетчерского узла «ГорСветТехКонтроль» северного города. Организация маскируется под коммунальную службу (ремонт лифтов, сетей, списание трамваев), но в реальности занимается **консервацией пространственных и акустических аномалий**, изолируя их ценой жизней людей.

Игрок — случайный оператор, перехвативший незашифрованную ночную сессию дежурного.

### Атмосферные и геймдизайн-особенности:
- **Никакой графомании**: Короткие сообщения пейджера, сухие выписки из БТИ, протоколы аварий.
- **Смена фокуса каждые 60–90 секунд**: Чат $\rightarrow$ ИК-камера 144p $\rightarrow$ база данных $\rightarrow$ радиосканер $\rightarrow$ перехват консоли.
- **Встроенный Web Audio API синтезатор**: 50 Гц гул трансформатора, щелчки реле, радиопомехи, тревожные сирены, дозиметр, инфразвуковой удар — без внешних аудиофайлов.
- **ЭЛТ-фильтры (CRT)**: Сканлайны, виньетка, глитчи, реакция на приближение аномалий.

## 3. Секретный Финал (4-я стена)

При вводе полного 4-значного составного кода в Терминал Допуска:
$$\mathbf{19 - 98 - 04 - 44}$$
*(1998 год, 4-й месяц, квартира 44а — эпицентр и дата первой катастрофы)*:

1. Подсветка узла гаснет под 50 Гц гул трансформатора.
2. Открывается секретное «ЛИЧНОЕ ДЕЛО ОПЕРАТОРА» с реальной телеметрией вашего устройства (местное время, часовой пояс, тип системы).
3. На схеме города появляется 5-я пульсирующая красная точка:
   > **«ВАШЕ ТЕКУЩЕЕ МЕСТОПОЛОЖЕНИЕ. ДАТЧИК ПРИСУТСТВИЯ: 2 ЧЕЛОВЕКА».**
