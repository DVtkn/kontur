# ГЕЙМДИЗАЙН-ДОКУМЕНТ И РЕЖИССЕРСКАЯ БИБЛИЯ ДЛЯ КОМПАНИИ ДРУЗЕЙ

> **Версия документа:** 3.0.0 (Master Co-Op Edition)  
> **Жанр:** Кооперативный детективный техно-триллер / Асимметричная головоломка для компании / Аналоговый хоррор  
> **Количество игроков:** 2–6 человек (Оптимально: 3–4 человека)  
> **Форматы игры:** 
> 1. *«Диванный штаб»* (Couch Co-op): Общий экран (ТВ/монитор) + смартфоны игроков через QR-код.
> 2. *«Удаленный дежурный узел»* (Online Co-op): Игра по сети (Discord / браузерная комната с кодом лобби).
> 3. *«Один терминал (Следственный совет)»*: Совместное обсуждение за одним экраном.  
> **Хронометраж кампании:** 4–6 часов (5 полноценных эпизодов с сохранением прогресса).  
> **Возрастной ценз:** 16+ (Психологический ужас, бытовой саспенс, производственный заговор, без скримеров-пустышек).

## 1. Введение и концепция продукта (High Concept)

### 1.1. Главная идея
**«КОНТУР»** для компании друзей — это гибрид камерного детективного квеста (*Sherlock Holmes Consulting Detective, Chronicles of Crime*), асимметричного технологического триллера (*Keep Talking and Nobody Explodes, We Were Here*) и мрачной городской мистики в духе советского крипи-лора, SCP Foundation и сериала «Чернобыль».

Компания друзей берет на себя управление ночной сменой **«Узла-70»** — законсервированного командного пункта муниципальной службы **«ГорСветТехКонтроль» (ГСТК)**. По официальным бумагам служба меняет лампы в фонарях и ремонтирует трамвайные пути. На деле — она уже 30 лет изолирует пространственно-акустический разлом, возникший в ночь с 14 на 15 апреля 1998 года после исчезновения трамвая №314.

### 1.2. Фундаментальный принцип: Асимметрия информации
Ни один участник компании не видит всей картины целиком. Игра построена так, что **пройти её в одиночку невозможно**:
- Один игрок слышит искаженный голос из рации и видит амплитуду звуковой волны.
- Второй держит в руках засекреченную схему подземных тоннелей БТИ 1978 года.
- Третий читает расшифровку допроса стрелочницы и видит нестыковки во времени.
- Четвертый управляет аварийными тумблерами на центральном пульте.

Чтобы разгадать тайну и не допустить катастрофы, друзья **обязаны разговаривать, спорить, зачитывать показания вслух, сверять часы и проверять гипотезы**.

## 2. Командные роли и специализации (Party Roles)

В начале игры каждый участник выбирает служебное удостоверение дежурной смены. На персональный смартфон игрока (или во вкладку браузера) загружается его личный рабочий инструмент.

```
                      ┌────────────────────────────────────────┐
                      │      ГЛАВНЫЙ СИТУАЦИОННЫЙ ЭКРАН        │
                      │  (ТВ / Проектор / Общий монитор смены) │
                      │  • Интерактивная карта города          │
                      │  • Доска улик со связями в реальном    │
                      │    времени                             │
                      │  • Шифратор допуска (19-98-04-44)      │
                      │  • Общие аварийные таймеры             │
                      └───────────────────┬────────────────────┘
                                          │
       ┌──────────────────┬───────────────┴──────────────┬──────────────────┐
       │                  │                              │                  │
┌──────▼──────┐    ┌──────▼──────┐                ┌──────▼──────┐    ┌──────▼──────┐
│  ДИСПЕТЧЕР  │    │ АРХИВАРИУС  │                │   АКУСТИК   │    │  ИНЖЕНЕР-   │
│  (Консоль)  │    │ (Досье/БТИ) │                │ (Радио/Код) │    │ ТЕЛЕМЕТРИСТ │
└─────────────┘    └─────────────┘                └─────────────┘    └─────────────┘
```

### Роль 1: Старший Диспетчер (Dispatch Controller)
* **Инструменты:** Центральный пульт управления шлюзами, тумблеры подачи напряжения, ввод аварийных команд консоли, управление таймерами изоляции.
* **Что видит только он:** Статусы гермодверей, протоколы блокировки, красные сигналы аварийной телеметрии, кнопки подтверждения приказов («ИЗОЛИРОВАТЬ», «ОТМЕНИТЬ», «ПЕРЕЗАГРУЗИТЬ»).
* **Ответственность:** Принимает финальное решение после согласования с командой. Нажимает физические тумблеры.

### Роль 2: Архивариус-Криминалист (Records & Forensic Archivist)
* **Инструменты:** Оцифрованные папки уголовных дел 1998 года, выписки из домовых книг, схемы БТИ, личные карточки сотрудников, протоколы допросов свидетелей.
* **Что видит только он:** Подлинные фамилии, табельные номера, даты рождения, рукописные пометки следователей на полях, несостыковки в показаниях свидетелей.
* **Ответственность:** Сверяет данные, которые сообщают жильцы или сущность, с официальными документами, выявляя фальсификацию и ложь.

### Роль 3: Акустик-Криптоаналитик (Signals & Cipher Officer)
* **Инструменты:** Радиосканер служебных частот (100–108 FM, ДВ/КВ диапазоны), спектрограф звуковых волн, дешифратор морзе и ведомственных шифроблокнотов, аудиофильтр подавления помех.
* **Что видит и слышит только он:** Перехваченные аудиосигналы, искаженные голосовые сообщения, звуки перестука в трубах, скрытые частоты радиомаяков.
* **Ответственность:** Слушает записи в наушниках, напевает или отстукивает ритм коллегам, диктует частоты и расшифрованные числовые последовательности.

### Роль 4: Инженер-Телеметрист (Infrastructure & Telemetry Engineer)
* **Инструменты:** Принципиальные схемы электроснабжения города, щитки ТСЖ, лазерные дальномеры БТИ, тепловые карты фундаментов, датчики давления в трубах и вентиляции.
* **Что видит только он:** Номера силовых фидеров, расчет нагрузок по фазам, показания бесконечной глубины лазерного луча, параметры криогенной заморозки.
* **Ответственность:** Вычисляет аномальные квартиры, находит перегруженные подстанции, указывает Диспетчеру правильные номера цепей для отключения.

### Роль 5: Полевой Аналитик / Профайлер (Forensic Profiler) — *для компании от 5 человек*
* **Инструменты:** Мониторинг домовых чатов, дамп смартфона Воронова, психолингвистический определитель речевых аномалий (выявление имитатора).
* **Что видит только он:** Анализ сообщений соседей, скрытые удаленные строчки переписки, сопоставление фото фасада с номерами квартир.

## 3. Архитектура и механики для компании (Group Play Dynamics)

### 3.1. Механика «Следственной доски» (Shared Evidence Board)
Все игроки видят общую доску расследования на главном экране (или синхронизированную на планшетах).
- По мере нахождения зацепок на доске появляются **«Улики»** (полароидные снимки, вырезки из протоколов, фрагменты аудиограмм).
- Игроки могут **соединять улики красными нитями**, проверяя гипотезы:
  - Например, соединение улики *«Табельный жетон 714 у замерзшего тела»* с уликой *«Путевой лист вагона №314»* открывает скрытую служебную пометку: *«Водитель Соколов вел трамвай за 45 минут до своей официальной гибели»*.
- При правильном соединении улик доска выдает ведомственный вывод и продвигает общий сюжет.

### 3.2. Механика «Коллективного кворума» (Quorum Protocol)
В моменты кризиса система переходит в режим голосования:
- На экраны каждого игрока выводятся варианты действий (например: *«Заморозить шлюз В-2 вместе с телами»* ИЛИ *«Снять пломбу и открыть гермодверь»*).
- Дается 90 секунд на живое обсуждение за столом.
- Игроки голосуют со своих смартфонов.
- Если мнения разделились поровну — решающий голос принадлежит Старшему Диспетчеру, но последствия влияют на статус расследования всех участников.

### 3.3. Механика «Паразитного заражения» (Unreliable Interface & Phone Ring)
- **Звонок на телефон игрока:** В кульминационные моменты (например, при допросе в Квартире 44а) браузер на смартфоне одного из игроков издает виброзвонок старого дискового аппарата. Игрок прикладывает телефон к уху и слышит шёпот сущности, адресованный лично ему: *«Скажи им, чтобы отключили рубильник 4... среди вас есть предатель...»*. Игрок должен сам решить, передавать ли эти слова друзьям или умолчать.
- **Искажение данных:** На экране одного игрока цифра в документе внезапно заменяется на искаженный символ. Друзья должны перепроверить его данные по своим архивам.

## 4. Глубокий сквозной сюжет (The Long Narrative Arc)

### 4.1. Предыстория трагедии: Проект «Контур-70» (1970–1998)
* **1974 год:** При строительстве глубокого спецколлектора для нужд ПВО и трамвайного тоннеля в районе улицы Лесной строители натыкаются на геологическую каверну с аномальными акустическими свойствами (звук внутри каверны не затухает, а усиливается во времени).
* **1982 год:** Минжилкомхоз создает закрытое подразделение **«ГорСветТехКонтроль» (ГСТК)**. Официальная задача — прикрытие объекта. Ученые выясняют: полость резонирует на низких частотах и способна «захватывать» сознание людей, повторяя их голоса и воспоминания (феномен «Эхо-камеры»).
* **14 апреля 1998 года (Ночь Катастрофы):** 
  - В 23:45 трамвайный вагон КТМ-5М3 (бортовой №314) под управлением водителя Соколова И.В. выезжает на последний рейс по маршруту «Южное кольцо — Северный тупик». В салоне — 12 пассажиров (среди них — кондуктор Мельникова, дежурный электромонтер, студенты, возвращавшиеся с ночной смены).
  - На стрелочном переводе №3 диспетчер с кодом `3140` переводит стрелку на законсервированный технологический спуск в подземелья РЛС-4.
  - Трамвай не врезается — он на полной скорости уходит по рельсам вглубь скальной породы прямо в полость резонатора.
* **15 апреля 1998 года (Сокрытие):** 
  - Руководство ГСТК во главе с главным инженером Казанцевым принимает бесчеловечное решение: не эвакуировать пассажиров, а залить сошедший вагон 400 тоннами бетона марки М500 прямо в монолит фундамента строящегося девятиэтажного дома (будущий дом №3 по ул. Лесной).
  - Людей внутри вагона используют как **биологический волногаситель** — живой демпфер, удерживающий пространственный разлом от расширения на город.
  - Родственникам заявляют об аварии без вести пропавших, уголовные дела изымаются, а шахта лифта на 4 этаже закладывается кирпичом.
* **Настоящее время (Ночь смены игроков):** 
  - Спустя почти 30 лет бетон фундамента дал микротрещины из-за незаконного бурения в подвальной «Квартире 44а». Биологический контур разрушается. Аномалия начинает просачиваться через домофоны, электросети и старые радиочастоты.
  - Дежурная смена сбежала. Сессия перехвачена группой игроков.

### ЭПИЗОД 0: «Перехват смены №4» (Пролог-обучение, 25–30 минут)
* **Цель эпизода:** Обучить команду командному взаимодействию, распределить роли и ввести в зловещую атмосферу.
* **Сюжет:** В 02:00 ночи экраны компьютеров и телефонов игроков подключаются к нешифрованному ведомственному протоколу «Узла-70». В эфире звучит тревожный сигнал зуммера. Предыдущий дежурный оставил незаконченную служебную записку: *«Оно больше не держится на бетоне. Кто заступил на смену — не открывайте шлюзы никому, даже если услышите свои голоса»*.
* **Командная загадка 0.1 (Синхронизация частот):**
  - Акустик крутит ручку настройки и находит несущую частоту служебного зуммера (73.4 МГц).
  - Инженер сверяет фазовый сдвиг генератора и диктует Диспетчеру код стабилизации.
  - Диспетчер активирует центральную консоль.

---

### ЭПИЗОД I: «Шлюз В-2. Тайна двенадцати» (50–60 минут)
* **Локация:** Подземный бункер спецобъекта «РЛС-4».
* **Завязка:** Срабатывает датчик тихого проникновения в гермошлюзе В-2. Камера отключена, температура падает до -6°C. На пейджер Диспетчера пишет «техник Соколов», умоляя открыть дверь, утверждая, что внутри заперты замерзающие монтажники.
* **Командная цепочка расследования:**
  1. **Инженер** восстанавливает питание видеокамеры через переключение шины резервного питания на своей схеме подстанции.
  2. **Диспетчер** выкручивает ИК-подсветку: на экране проявляются 11 застывших фигур спиной к камере и 12-я фигура в сантиметре от объектива с открытым глазом. На стене виден меловой номер `714`.
  3. **Архивариус** по запросу команды открывает закрытую картотеку личного состава ГСТК и вводит табельный номер `714`:
     - *Шокирующая находка:* Карточка принадлежит Соколову И.В. Био-браслет фиксирует пульс **0 уд/мин уже 45 минут**, а координаты трупа — **внутри шлюза**.
     - Тот, кто пишет в чат снаружи — не человек, а имитатор.
  4. **Акустик** прослушивает аудиоканал у двери шлюза: сквозь стук слышны неестественные звуки дыхания и реверберация чужих телефонных разговоров.
  5. **Кульминация (Таймер 90 секунд):** Сущность понимает, что разоблачена, и начинает физически срезать внешний замок автогеном. Текст в чате искажается: `«ПУСТИТЕ НАС В ГОРОД»`.
  6. **Решение команды:** Команда проводит голосование и активирует вентиль экстренной крио-заморозки шлюза кодом подтверждения `714`.
* **Награда:** Шлюз покрывается инеем, на экране проступает первый ведомственный фрагмент: **`[ 19 ]`**.

### ЭПИЗОД II: «Лесная, 3. Фантомный этаж» (60–75 минут)
* **Локация:** Жилой девятиэтажный дом, возведенный над местом схода трамвая.
* **Завязка:** На пульт поступает перехват дампа смартфона жильца дома Олега Воронова (кв. 45), найденного на скамейке у подъезда. Сам Воронов исчез. В домовом чате «ЖК Лесной» происходит жуткая переписка.
* **Командная цепочка расследования:**
  1. **Полевой Аналитик / Диспетчер** анализирует чат жильцов:
     - Жильцы жалуются на собачий вой в вентиляции человеческим голосом.
     - Сообщение Светланы (кв. 8) на глазах стирается и заменяется машинной строкой: *«Ошиблась окно есть отличный вид пусть стоит хороший человек»*.
  2. **Акустик** воспроизводит перехваченное 3-секундное голосовое сообщение Светланы. Сквозь фильтры он разбирает панический шепот: *«Оно за кирпичной стеной лифта... не гасите свет в 38-й... лицевой счет 8804...»*.
  3. **Архивариус** поднимает план дома 1998 года из архива ЖЭУ №2:
     - Оказывается, шахта лифта на 4 этаже заложена глухой кирпичной кладкой по спецраспоряжению после катастрофы. За стеной нет этажа — там пустая вертикальная полость, уходящая в фундамент.
  4. **Инженер** подключается к распределительному щитку ТСЖ:
     - Находит лицевой счет `8804`. Чтобы обесточить паразитную петлю, питающую аномалию, нужно указать номер квартиры, потребляющей 0 кВт/ч при включенных лампах.
  5. **Командная визуальная головоломка (Ночной фасад):**
     - Команда изучает фото ночного фасада дома. На 4 этаже в третьем подъезде одно окно абсолютно черное, хотя вокруг него виден легкий силуэт стоящей в темноте фигуры.
     - Сопоставив нумерацию квартир по этажам (4 квартиры на этаж) и данные Архивариуса, команда вычисляет номер темной квартиры: **квартира №38**.
  6. **Кульминация:** Сущность в домовом чате понимает, что её ищут. 64 аккаунта одновременно пишут одно слово: *«СМОТРИ»*. На смартфонах игроков кратковременно включается черный экран с мерцающим лицом.
  7. **Финал эпизода:** Инженер и Диспетчер вводят Л/С `8804` и номер квартиры `38`, обесточивая 4-й этаж.
* **Награда:** В логе щитка загорается штамп стабилизации и второй фрагмент шифра: **`[ 98 ]`**.

### ЭПИЗОД III: «Стрелка №3. Рейс в пустоту» (60–75 минут)
* **Локация:** Серверный архив ТТУ (Трамвайно-троллейбусного управления).
* **Завязка:** Команда получает доступ к закрытой базе происшествий за апрель 1998 года. Но как только архив открывается, активируется ведомственный сторожевой скрипт `[ID: ЧИСТИЛЬЩИК]`, который начинает безвозвратно стирать протоколы один за другим каждые 30 секунд.
* **Командная цепочка расследования:**
  1. **Архивариус и Полевой Аналитик** в панике спасают и конспектируют файлы, пока они не стерты:
     - Путевой лист трамвая №314 от 14.04.1998 (выезд 23:45, водитель Соколов, кондуктор Мельникова).
     - Протокол допроса дежурной стрелочницы: *«В 23:58 стрелка №3 перевелась сама... раздался звон, словно рельсы стеклянные... вагон ушел в тоннель, которого не было на схеме»*.
  2. **Акустик** находит пометку о бортовой рации и настраивает сканер на частоту **`104.2 FM`**:
     - Из динамиков доносится страшная запись черного ящика вагона №314: стук колес, женский крик кондуктора, скрежет металла и монотонный голос диспетчера, диктующий бесконечный ряд чисел.
  3. **Криптоаналитик и Инженер** декодируют ряд чисел из эфира: это служебный диспетчерский пароль аварийной блокировки стрелки — **`3140`**.
  4. **Диспетчер** открывает защищенную консоль перехвата:

  5. **Кульминация:** За секунду до полного форматирования диска бот блокируется. На экране восстанавливается засекреченная фотография 1998 года: в подвале дома стоит вмурованный в бетон нос трамвайного вагона №314 со светящимися фарами.
* **Награда:** В служебной строке депо проявляется третий фрагмент шифра: **`[ 04 ]`**.

### ЭПИЗОД IV: «Спецколлектор 44а. Монолит» (70–80 минут)
* **Локация:** Подвальный бункер под домом на Лесной, 3.
* **Завязка:** В подвале дома работает аварийная бригада буровиков, нанятая коммерческим застройщиком. Они собираются пробить несущую стену замурованной квартиры 44а, чтобы расширить подземный паркинг. На центральном пульте тикает таймер: **до начала бурения осталось 12 минут**. Если они пробьют стену — резонатор вырвется в город.
* **Командная цепочка расследования:**
  1. **Инженер** анализирует акт обмера БТИ:
     - Прибор лазерного дальномера (Hilti-98), направленный в технологическое отверстие стены кв. 44а, показывает статус `ZERO_RETURN` — **луч света не возвращается назад ($L = \infty$)**. Пространство за стеной бесконечно.
  2. **Архивариус** зачитывает служебную записку слесаря Петрова:
     - Рабочие отказываются спускаться в подвал, так как из-за кладки слышны голоса их умерших родственников, которые просят принести инструменты.
  3. **Интерактивный телефонный допрос (Кульминация эпизода):**
     - Внезапно звонит внутренний ведомственный телефон начальника смены (или телефон одного из игроков за столом!).
     - На проводе — голос «Главного инженера Казанцева»:
       > *«Слушайте меня внимательно. Бурение нельзя останавливать! За стеной скопился метан, если мы не пробьем отдушину — весь дом взлетит на воздух. Немедленно подпишите ордер на снос!»*
     - **Задача команды:** Разоблачить самозванца!
     - Архивариус открывает «Устав спецконтроля ГСТК от 1998 года»:
       - Параграф 12.4: *«При угрозе резонанса любые строительные работы караются высшей мерой изоляции. Лица, требующие разрушения монолита, признаются носителями имитационной инфекции»*.
       - Параграф 18.1: *«Казанцев В.П. погиб при консервации объекта 16 апреля 1998 года»*. Человек на проводе мертв уже 30 лет.
  4. **Командный вердикт:** Команда отвергает требования сущности и вводит резолюцию: **`ОТМЕНА НАРЯДА // КАРАНТИН БЕЗ СРОКА ДАВНОСТИ`**.
* **Награда:** Буровые установки дистанционно обесточиваются. На экране загорается финальный четвертый фрагмент: **`[ 44 ]`**.

### ЭПИЗОД V: «Судный протокол. Деанонимизация» (Грандиозный финал, 45–50 минут)
* **Кульминация всей игры.**
* **Действие 1: Ввод полного мастер-кода.**
  - Команда собирает все 4 фрагмента: **`19` - `98` - `04` - `44`**.
  - Дата катастрофы: **14.04.1998**, сектор **19**, эпицентр **44**.
  - Диспетчер торжественно вводит цифры в Терминал Допуска на главном экране.
* **Действие 2: Полный блэкаут и аудиальный удар.**
  - Экран гаснет. Звучит глухой низкочастотный инфразвуковой удар (28 Гц).
  - Включается гул силового трансформатора (50 Гц).
  - Все подключенные смартфоны игроков в комнате начинают синхронно вибрировать.
* **Действие 3: Четвертая стена и деанонимизация компании.**
  - На экраны выводится реальная телеметрия участников сессии:
    - Точное местное время в городе игроков (например: `03:42:18`).
    - Платформы их устройств, операционные системы и разрешения экранов.
  - Медленно печатается вердикт ведомства:
    > *«Внимание дежурной смене. Вы раскрыли материалы дела категории "Омега". По инструкции 1998 года свидетели консервации подлежат бессрочному включению в контур наблюдения. Ваша сессия не была перехватом. Вы были вызваны на смену»*.
* **Действие 4: Пятая точка на радаре (Психологический кульминатор).**
  - На главном экране загорается радар. В центре — координаты квартиры/комнаты, где прямо сейчас сидят друзья.
  - Вращающийся луч радара делает оборот и ставит красную точку прямо по центру:
    `«ДАТЧИК ПРИСУТСТВИЯ В ПОМЕЩЕНИИ ОПЕРАТОРОВ: [КОЛИЧЕСТВО ИГРОКОВ + 1] ЧЕЛОВЕК»`.
  - В тишине раздается один тихий стук в дверь или окно.
* **Действие 5: Финальный коллективный выбор команды (3 Концовки):**
  1. **Концовка А («Печать забвения»):** Команда нажимает кнопку «СТЕРЕТЬ АРХИВ И ПРИНЯТЬ СМЕНУ». Они становятся новыми бессмертными смотрителями контура. Город спит спокойно ценой их свободы.
  2. **Концовка Б («Прорыв правды»):** Команда выгружает файлы во внешний интернет. Сирены воют по всему городу, тайна 1998 года раскрыта, но аномалия вырывается на свободу.
  3. **Концовка В («Секретный протокол 714»):** Если игроки соединили все 8 скрытых улик на доске — активируется протокол обратной перемотки времени, спасающий вагон №314 до схода.

## 6. Детальная спецификация типов загадок (Puzzle Taxonomy)

| Тип загадки | Роли-участники | Входные данные | Механика решения | Проверка ошибки |
| :--- | :--- | :--- | :--- | :--- |
| **Крипто-аудио** | Акустик + Диспетчер | Морзе / помехи на 104.2 FM | Слуховой анализ, подбор несущей частоты | При ошибке частоты — белый шум бьет по ушам |
| **Судебно-архивная** | Архивариус + Профайлер | Карточки 1998 г. + Чат | Поиск алиби, выявление несоответствий дат и пульса | Если поверить имитатору — таймер сокращается вдвое |
| **Геодезическая** | Инженер + Архивариус | Планы БТИ + Фото окон | Фасадный расчет (этаж $\times$ шаг квартир), поиск темноты | Выбивает пробки щитка, блокировка на 20 сек |
| **Консольная дуэль** | Диспетчер + Вся группа | Команды стирания памяти | Быстрый командный ввод диспетчерских директив | Стирание папки с уликой при промедлении |
| **Перекрестный допрос** | Профайлер + Архивариус | Аудиозвонок имитатора | Сверка ответов собеседника с пунктами Устава ГСТК | Если согласиться на снос — мгновенный срыв контура |

## 7. Техническая архитектура мультиплеера (Web Tech Stack)

```
                            ┌────────────────────────┐
                            │    VITE + REACT 19     │
                            │   (Центральный хаб)    │
                            └───────────┬────────────┘
                                        │ WebSockets / PeerJS
                   ┌────────────────────┼────────────────────┐
                   │                    │                    │
        ┌──────────▼─────────┐ ┌────────▼──────────┐ ┌───────▼──────────┐
        │  МОБИЛЬНЫЙ КЛИЕНТ  │ │ МОБИЛЬНЫЙ КЛИЕНТ  │ │ МОБИЛЬНЫЙ КЛИЕНТ │
        │    (Игрок 1: QR)   │ │   (Игрок 2: QR)   │ │   (Игрок 3: QR)  │
        └────────────────────┘ └───────────────────┘ └──────────────────┘
```

1. **Без установки приложений (Zero Friction):**
   - На экране главного компьютера отображается динамический QR-код сессии: `http://kontur.local/?room=SEVER98&role=acoustic`.
   - Друзья наводят камеры телефонов и за 1 секунду подключаются к лобби прямо в мобильном браузере (Safari / Chrome).
2. **Протокол синхронизации состояния (State Synchronization):**
   - Использование легкого WebRTC (PeerJS) или локального WebSocket-сервера.
   - Минимальный объем трафика (передаются только ID событий, состояние тумблеров и флаги прогресса).
3. **Web Audio API + Haptic Vibration:**
   - На смартфонах игроков используется `navigator.vibrate([100, 50, 100])` для эмуляции звонков, перегрузок сети и сердцебиения.
   - Синхронное воспроизведение низкочастотных звуков между всеми устройствами в комнате.
